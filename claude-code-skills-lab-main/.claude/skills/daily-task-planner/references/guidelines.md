# Daily Time-Aware Task Planner - Reference Guide

## Overview
The Daily Time-Aware Task Planner helps office employees organize their tasks within a single workday, considering time constraints and energy levels throughout the day.

## Default Working Hours
- Standard office day: 9:00 AM – 6:00 PM
- Morning (9-12 PM): High focus capacity
- Afternoon (12-4 PM): Medium focus capacity
- Late afternoon (4-6 PM): Lower energy, suitable for lighter tasks

## Task Categorization
The system categorizes tasks based on:
- Duration (estimated from task description)
- Priority (high, medium, low)
- Effort level (high_focus, medium_focus, low_focus)

## Scheduling Logic
1. High-priority, high-focus tasks are scheduled in the morning
2. Medium tasks are scheduled in the afternoon
3. Low-effort tasks are scheduled in the late afternoon
4. Breaks are suggested between intensive work periods

## Warning Indicators
The system will warn about:
- Overloaded schedules
- Unrealistic task placement
- Insufficient focus time
- Conflicting time commitments

## Tips Provided
Practical, beginner-friendly advice to help users optimize their day.
