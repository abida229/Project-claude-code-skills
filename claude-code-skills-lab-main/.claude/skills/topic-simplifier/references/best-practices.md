# Topic Simplifier - Best Practices

## Creating Effective Learning Breakdowns

### Definition Guidelines
- Keep definitions to one clear, simple sentence
- Use everyday language that anyone can understand
- Avoid technical jargon or explain it immediately
- Focus on what the concept does or means, not how it works internally

### Example Selection
- Choose real-world examples that are familiar to most people
- Include diverse examples to appeal to different backgrounds
- Make examples concrete rather than abstract
- Ensure examples clearly illustrate the concept

### Mind Map Creation
- Start with the main topic at the top
- Group related sub-topics together
- Use hierarchical structure (main topics, sub-topics, details)
- Keep branches manageable (no more than 3-4 levels deep)
- Use consistent terminology throughout

### Flow Diagram Guidelines
- Only create flow diagrams when the topic involves a process or sequence
- Keep steps clear and logical
- Use arrows to show direction of flow
- Include decision points if applicable
- Limit to 5-7 main steps for clarity

### Explanation Structure
- Start with the big picture before diving into details
- Connect sub-topics to the main concept
- Use analogies when helpful
- Build complexity gradually
- Link related concepts together

### Related Concepts Section
- Identify prerequisites needed to understand the main topic
- Include closely related concepts that are often confused
- Explain connections between related concepts
- Address common misconceptions
- Provide context for where each concept fits

### Clarifications Section
- Anticipate common points of confusion
- Address misconceptions directly
- Explain limitations or constraints
- Clarify technical terms
- Point out common mistakes to avoid

### Key Takeaways
- Limit to 3-5 most important points
- Make each takeaway actionable when possible
- Focus on practical applications
- Include memory aids if helpful
- Provide next steps for continued learning
